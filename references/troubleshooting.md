# 常见问题与解决方案（健壮性手册）

本文件汇总淘宝88VIP下单过程中可能遇到的问题、原因分析和应对方案。
遇到问题时先在此查找对应条目，按方案处理；未覆盖的问题截图报告。

---

## 一、红包相关

### 1. 红包显示"不可用"

**已知原因**：
- 红包每日0点自动发放到卡券包，当天有效，第二天过期。如果当天已用过一次，当日不会再发。
- 红包有使用门槛：满2.01元可用。商品价格不满则不显示抵扣。
- 红包不支持虚拟类目（话费、游戏点卡、门票、投资金等），实物商品一般可用。
- 部分红包限定特定渠道（百亿补贴专享、饿了么专享），通用红包才能用于本商品。
- 红包不会自动选中，需要在确认订单页手动勾选。

**排查步骤**：
1. 确认订单页点击"红包"行展开面板，看是否有红包未被勾选。
2. 去"我的淘宝-红包卡券-未使用"查看今日是否有2元通用红包。
3. 如果红包列表里没有今日红包 → 可能今天已用过，或0点尚未到账（极个别情况有延迟，等几分钟刷新）。
4. 如果有红包但显示"不可用" → 查看不可用原因（品类限制/门槛不满足），换商品或放弃本单。

**重要**：88VIP天天2元红包是自动发放的，不需要手动点击领取按钮。88VIP中心的"天天2元红包"卡片只是介绍页，不是领取入口。

### 2. 红包金额不对（不是-2.00）

- 确认商品总价是否满足"满5减3"后的价格为2.01元。如果商品涨价或店铺优惠变了，红包抵扣后总额会偏离0.01。
- 检查是否有其他红包/优惠券叠加导致金额异常。
- 金额不对时**不要提交**。

## 二、风控与限制

### 3. 提示"下单人数过多"/"活动火爆"/"请稍后再试"

这是淘宝风控拦截（俗称"被盾了"），不是真的人多。

**解决方案（按优先级）**：
1. 不要连续点击提交按钮，等待至少30分钟。
2. 退出当前页面，重新打开商品页，先浏览3-5分钟（滚动、看评价），不要秒进秒出。
3. 检查收货地址是否详细（要有门牌号），地址太模糊会触发风控。
4. 如果是临时风控，通常1-2小时后自动恢复。不要短时间反复尝试。
5. **不要换网络/换设备**——浏览器自动化环境固定，切换反而更可疑。保持正常节奏即可。

### 4. 提示"当前交易存在风险"/"安全验证"

- 这是强风控，必须人工处理。
- 立即停止，调用 `interaction.request_action` 交还用户。
- 不要尝试自动通过滑块/人脸验证。

### 5. 订单提交后被系统自动关闭/退款

可能原因：
- 同设备/同收货人/同手机号短时间内下多单触发限购。
- 系统判定交易异常（价格异常、地址异常）。
- 商家因缺货或价格问题主动关单。

**应对**：
- 记录订单号和关闭原因。
- **不要立即重新下单**。等待至少24小时。
- 如果连续被关单，说明账号已被标记，停止后续定时任务，报告用户。

### 6. 账号被限制下单

- 如果出现"账号被处罚，不允许购买"等提示，这是账号级限制。
- 立即停止所有操作，报告用户。不要尝试绕过。
- 通常需要联系淘宝客服9510211解除。

## 三、支付方式相关

### 7. "先用后付"不可用

- 先用后付需要芝麻信用分≥550分才能开通。
- 如果确认订单页没有"先用后付"选项或显示不可用：
  - 检查是否已开通：我的淘宝 → 设置 → 支付 → 先用后付。
  - 如果未开通，**不要自行开通**（需要用户确认），报告用户手动处理。
  - 不要用支付宝/花呗等其他方式替代——金额会不对。

### 8. 提交后跳转到支付宝要求付款

- 说明"先用后付"未生效，或订单实际金额不是0.01。
- **不要输入任何支付密码**。
- 退回确认订单页，检查支付方式是否选对。
- 如果已跳转到支付宝收银台，关闭该标签页，不要付款。

## 四、页面与技术问题

### 9. 页面跳转到登录页

- 会话过期。按安全约束处理：交还用户登录，不要自动登录。
- 登录后需要重新从商品页开始。

### 10. 商品页SKU选中状态丢失

- URL中带skuId通常会自动选中。如果页面刷新后SKU变了：
  - 截图确认当前选中的SKU。
  - 用 TypeSafe 判断是否正确。
  - 不对则点击正确SKU后重新确认。

### 11. 确认订单页金额数字读不准

- 不要靠DOM文本猜数字。
- 截图后用 TypeSafe 做 noul 判断"合计是否为0.01"。
- TypeSafe 判断置信度低（0.3-0.7）时，放大截图人工确认。

### 12. 提交订单后白页/转圈

- 不要重复点击提交按钮。
- 等待10秒后导航到"已买到的宝贝"列表，检查是否已生成订单。
- 如果列表里有新订单 → 提交成功，继续验证。
- 如果列表里没有 → 提交可能失败，等待2分钟后再查一次。仍无则报告"提交结果不确定"。

### 13. 浏览器会话断开（BU_SESSION_STALE）

- 调用 `bu.resync()` 重新连接。
- 如果重连后页面丢失，重新导航到商品页从头开始。
- 如果连续断开2次，报告并交还用户。

### 14. 88VIP中心页面内容渲染不出

- 88VIP中心页面使用Shadow DOM，DOM快照可能读不到卡片。
- 直接截图后用坐标点击对应位置。
- 但实际上2元红包是自动发放的，不需要手动领取。如果红包不可用，去"我的淘宝-红包卡券"查看即可，不必反复尝试88VIP中心。

## 五、时间与频率问题

### 15. 当天红包已用过

- 88VIP每天只有1个2元红包，0点发放，当天有效。
- 如果当天已经用了（包括之前的手动下单），定时任务触发时红包不可用是正常的。
- 此时跳过该单，报告"今日红包已使用，本单未下"，不要强行用其他方式下单。

### 16. 三单间隔太短被风控

- 两单之间至少间隔4小时。
- 如果第1单在晚上23:00，第2单在第二天10:00，间隔约11小时，安全。
- 不要为了赶时间窗口而缩短间隔。

## 五补、商品与账号状态问题

### 16a. 商品已下架/不存在/无库存

**现象**：商品页显示"宝贝不存在"、"页面不见了"、"该商品已下架"或SKU置灰无法选择。

**处理**：
- 这不是临时问题，商品已失效。
- 停止本单，记录 `status: failed`，note 写明"商品已下架"。
- 不要尝试换商品或换SKU——金额逻辑会变。
- 报告用户：需要更换商品链接后重新启动。

### 16b. 商品价格变动导致金额不匹配

**现象**：商品页价格不是预期的¥5.01（或满减后不是¥2.01）。

**原因**：商家调价、活动结束、店铺优惠变化。

**处理**：
- 不要提交订单。
- 记录实际价格和计算结果，报告用户。
- 如果只是店铺优惠从-3变成其他金额，红包抵扣后总额必然偏离0.01，必须人工确认是否接受新价格。

### 16c. 88VIP会员已过期

**现象**：我的淘宝页面不显示88VIP标识，或确认订单页无红包抵扣。

**处理**：
- 88VIP过期后不会每天发2元红包。
- 检查页面上是否有"续费88VIP"提示。
- 不要自动续费，报告用户处理。

## 六、PC网页端特有问题

以下问题仅在电脑浏览器（buy.taobao.com）操作时可能出现：

### 17. "哎哟喂，被挤爆啦，请稍后重试"（RGV587_ERROR）

**现象**：页面显示"哎哟喂，被挤爆啦，请稍后重试"或返回 `FAIL_SYS_USER_VALIDATE / RGV587_ERROR`。

**原因**：淘宝PC端反爬/风控系统检测到异常访问频率或自动化行为。这不是真的服务器拥堵。

**处理**：
1. **不要立即刷新重试**——连续刷新会加重风控。
2. 等待至少10分钟后刷新页面。
3. 如果反复出现，等待30分钟以上。
4. 该限制通常是临时的，几小时后自动解除。
5. 如果持续超过1小时，停止操作，报告用户。

### 18. 确认订单页红包区域折叠，看不到抵扣明细

**现象**：buy.taobao.com 页面上金额只显示一个总数，看不到红包行。

**处理**：
1. 必须点击"查看付款详情"链接展开明细。
2. 展开后才能看到商品总价、店铺优惠、红包、平台优惠等分项。
3. 如果点击后没反应，截图确认；可能需要等待页面加载。

### 19. PC端红包不自动选中

**现象**：卡券包里有2元红包，但确认订单页显示"红包不可用"或红包金额为0。

**处理**：
1. 确认订单页点击"红包"行展开红包选择面板。
2. 检查2元红包是否在"可用红包"列表中，是否已勾选。
3. 如果红包在"不可用"列表中，查看原因（品类/门槛限制）。
4. PC端有时不会自动选中最优红包，需要手动勾选。

### 20. PC端跳转到手机版页面

**现象**：打开商品页后被重定向到 `m.taobao.com` 移动端页面。

**处理**：
1. 检查URL，如果是 `m.taobao.com`，手动改为 `item.taobao.com` 桌面版URL。
2. 确保浏览器UA是桌面Chrome（browser-use环境默认是桌面UA，一般不会触发）。
3. 如果反复跳转，清除该站点cookie后重新登录。

### 21. PC端红包查看路径

- PC端查看红包：登录淘宝后，鼠标悬停右上角用户名 → 点击"我的淘宝" → 左侧"我的卡券包" → 红包。
- 或直接访问：`https://i.taobao.com/my_itaobao/coupon?defaultTab=redEnvelope`
- 注意：部分红包规则说明中提到"淘宝APP-我的淘宝-我的权益-红包"，PC端对应位置在"我的淘宝-我的卡券包"。

### 22. PC端确认订单页Shadow DOM/动态渲染

**现象**：DOM快照(snapshot)只读到导航栏，读不到商品明细、金额等内容。

**处理**：
1. 这是因为淘宝PC页大量使用Shadow DOM和动态渲染。
2. 用 `bu.screenshot()` 截图后通过视觉确认。
3. 用 `bu.get_page_text()` 获取完整文本（通常能拿到），保存后交给TypeSafe判断。
4. 不要依赖 `bu.find()` 查找深层元素，优先截图+TypeSafe。

### 23. PC端"先用后付"选项位置

- PC端确认订单页底部有支付方式选择区域。
- "先用后付"是一个圆形单选按钮，与"支付宝"、"朋友代付"并列。
- 需要确认它已被选中（有对勾标记）。
- 如果默认选中的是支付宝，**不要手动切换**——如果先用后付不可用，说明账号不满足条件，报告即可。

### 24. PC端提交按钮位置

- PC端确认订单页的"提交订单"按钮在页面右下角，橙色大按钮。
- 按钮上可能显示"提交订单"或"提交订单 ¥0.01"。
- 页面需要滚动到底部才能看到按钮（如果视口高度不够）。
- 用 `bu.scroll(500, 900, "down", amount=3)` 滚动到底部再截图确认。

```

├── 88VIP过期 → 停止，报告用户续费
├── 跳转到手机版(m.taobao.com) → 改回桌面版URL
├── 金额≠0.01
│   ├── 红包不可用 → 展开红包面板，检查是否未勾选
│   ├── 红包未选中 → 手动勾选2元红包
│   ├── 红包已用完 → 跳过本单
│   └── 商品价格变了 → 报告，不提交
├── 提交后要求付款 → 关闭页面，不付款，回查订单
├── "下单人数过多"/"交易风险" → 停止，不重试
├── 订单被关闭 → 等24小时，不重试
├── 今日已有成功订单 → 跳过，不重复下单
├── DOM读不到内容 → 截图+TypeSafe判断

```
