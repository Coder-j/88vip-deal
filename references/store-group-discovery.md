# 关注店铺分组商品推荐流程

当用户配置了 `store_group_name` 时，从淘宝关注店铺分组中自动发现 ¥2.01 商品并推荐。

## 步骤

### 1. 打开关注店铺页

```python
import seed_browser_use as bu
bu.navigate("https://i.taobao.com/my_itaobao/subscription")
bu.wait_for_load(timeout=15)
import time; time.sleep(3)
```

### 2. 定位分组

页面左侧/顶部有分组筛选标签（全部、常逛、买过、最近关注、特别关注、有上新、自定义分组名）。

- 用 `bu.find(store_group_name)` 找到对应分组标签并点击。
- 如果找不到分组名，截图让用户确认当前有哪些分组。
- 点击后 `page_wait()`，页面只显示该分组下的店铺。

### 3. 遍历店铺，收集 ¥2.01 商品

每个店铺卡片下会展示若干推荐商品。对每个店铺：

1. 读取店铺名（如"6元品牌集合店"）。
2. 读取该店铺展示的商品列表：每个商品有标题、价格、付款人数。
3. **筛选价格正好为 ¥2.01 的商品**——这些就是叠加满减+红包后 ¥0.01 的目标商品。
4. 记录：店铺名、商品标题、价格（确认是2.01）、付款人数、商品链接（hover 或点击获取）。

### 4. 汇总推荐表

按付款人数降序排列，输出表格：

| 店铺 | 商品标题 | 价格 | 付款人数 |
|---|---|---|---|
| 6元品牌集合店 | 奥妙洗洁精2元... | ¥2.01 | 10万+ |
| 6元品牌折扣店 | 奥妙洗衣液2元... | ¥2.01 | 5万+ |
| ... | ... | ... | ... |

**推荐优先级**：
- 优先选实物消耗品（纸巾、洗衣液、洗洁精、香皂等），不选虚拟商品。
- 付款人数多的商品库存稳定、售后风险低。
- 不同店铺的商品优先分散，避免连续从同一家店下单触发风控。

### 5. 用户选择后获取商品链接

1. 用户选定一个商品。
2. 点击该商品标题进入商品详情页。
3. 从浏览器 URL 中提取 `id` 和 `skuId`。
4. 截图确认 SKU 选中状态。
5. 将 item_url 和 item_title 写入配置。

## 注意事项

- 分组下可能有非 ¥2.01 的商品（如几千元的珠宝店），只推荐 ¥2.01 的。
- 商品列表是动态渲染的，用 `bu.get_page_text()` 读取，不要依赖 snapshot。
- 如果分组页只显示部分店铺，向下滚动加载更多。
- 每个店铺的商品卡片上直接显示价格和付款人数，不需要逐个点进去。
