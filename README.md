# 88VIP Deal Skill（88省钱）

利用淘宝88VIP每日自动发放的2元红包，在48小时内自动完成3笔¥0.01元订单的浏览器自动化技能。

## 它做什么

- 每天0点88VIP自动发1个2元淘宝天猫购物红包（当天有效）
- 本技能在48小时内自动下3单，每单凑满减+红包后实付¥0.01（先用后付，确认收货后付款）
- 三单时间窗口随机错开，模拟真人节奏，降低风控风险
- 关键决策点用 TypeSafe AI 做结构化判断，不靠肉眼猜DOM文本
- 每单前1小时自动预检登录态，结果通过聊天窗口推送
- 支持从淘宝关注店铺分组自动发现¥2.01商品并推荐

## 前置要求

| 条件 | 说明 |
|---|---|
| 淘宝88VIP会员 | 账号需已开通88VIP，有效期内 |
| 先用后付 | 芝麻分≥550，已开通先用后付 |
| 浏览器会话 | 使用前在浏览器中已登录淘宝PC端 |
| 商品选择 | 店铺满减后价格≈¥2.01的实物商品（如满5减3的洗洁精/湿巾） |
| TypeSafe API Key | 可选，用于结构化判断；未配置时降级为截图判断 |

## 安装

### 1. 克隆到技能目录

```bash
cd ~/.doubao/agent_mode/workspace/.user_skills/
git clone https://github.com/Coder-j/88vip-deal.git
```

### 2. 配置

```bash
cd 88vip-deal
cp assets/config.example.yaml assets/config.yaml
# 编辑 config.yaml 填入你的配置
```

配置项说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `store_group_name` | 二选一 | 淘宝关注店铺分组名（如"88vip羊毛"），设置后自动从该分组推荐¥2.01商品 |
| `item_url` | 二选一 | 商品页完整URL（含skuId）；不填则从分组推荐 |
| `item_title` | 否 | 商品名称（用于核对） |
| `expected_shop_discount` | 否 | 店铺优惠金额，默认3.00 |
| `expected_red_packet` | 否 | 红包抵扣金额，默认2.00 |
| `expected_total` | 否 | 预期合计应付，默认0.01 |
| `address_keyword` | 否 | 收货地址关键词（用于核对地址一致） |
| `payment_method` | 否 | 支付方式，默认"先用后付" |

### 3. 环境变量（可选）

```bash
export TYPESAFE_API_KEY="your-key-here"
```

不设置也能用，只是金额判断会降级为截图人工确认。

## 快速使用

在豆包/豆包Turbo中直接说：

**方式A：手动指定商品**
> "用88省钱技能帮我下单，商品链接是 https://item.taobao.com/item.htm?id=xxx&skuId=yyy"

**方式B：从关注店铺分组推荐（推荐）**
> "用88省钱技能，从我的'88vip羊毛'店铺分组里推荐商品下单"

技能会自动：
1. 检查淘宝登录态（过期则截图二维码发到对话让你扫码）
2. 从分组店铺中筛选¥2.01商品，列出推荐表供你选择
3. 打开商品页截图确认SKU
4. 计算3个随机下单时间
5. 创建3个下单任务 + 3个登录态预检任务（每单前1小时）
6. 到点自动执行下单+验证，结果通过聊天窗口推送

## 下单时间表

| 订单 | 时间窗口 | 说明 |
|---|---|---|
| 第1单 | 当天 21:00–23:30 | 用当天红包 |
| 第2单 | 次日 10:00–20:00 | 0点重置后用新红包 |
| 第3单 | 第三日 00:30–09:30 | 新一天红包，10点前完成 |

每单时间在窗口内随机取，不整点。两单间隔≥4小时。

## 登录态预检

每单执行前1小时自动检查登录态：

- **预检通过** → 聊天窗口推送："预检通过：登录态正常，预计 HH:MM 执行第N单"
- **登录过期** → 截图二维码发到对话，推送："预检发现登录已过期，请扫码重新登录"
- **睡眠窗口避让**：如果预检时间落在23:00–07:00，提前到当天23:00检查
- 预检失败不阻塞下单任务，下单时会再次检查

## 安全机制

- **金额严格校验**：合计必须=¥0.01才点提交，否则不提交
- **提交按钮只点一次**：不确定就去订单列表查，不重试
- **不碰密码/验证码**：遇到支付密码、短信验证、人脸，立即交还人工
- **不修改地址**：三单地址一致，只核对不更改
- **登录过期即截图二维码**：不让用户去浏览器找，直接发到对话扫码
- **红包不可用不硬下**：跳过该单并报告
- **订单去重**：下单前先查今日是否已有成功订单，防止重复提交
- **风控节奏**：页面间随机等待3-8秒，模拟真人操作
